## Quick Start

### Option 1: Automated Deployment (Easiest)

1. Push your code to GitHub/GitLab/Bitbucket
2. Go to [Render Dashboard](https://dashboard.render.com)
3. Click **"New +"** → **"Blueprint"**
4. Connect your repository
5. Render will detect `render.yaml` and create all services
6. Set environment variables (see `infra/RENDER.md` for details)
7. Deploy!

### Option 2: Manual Setup

Follow the detailed instructions in `infra/RENDER.md`

## Key Environment Variables

### Backend (`sara-api`)
- `CORS_ORIGINS` - Your frontend URL (required)
- `INVITE_EMAILS` - Allowed user emails (required)
- `JWT_SECRET` - Auto-generated by Render
- `DATABASE_URL` - Auto-set from database service

### Frontend (`sara-web`)
- `NEXT_PUBLIC_API_BASE_URL` - Your backend URL (required)

## Important Notes

1. **Database URL Format**: Render provides `postgresql://` but FastAPI needs `postgresql+psycopg://`. The `start.sh` script handles this automatically.

2. **Migrations**: Database migrations run automatically on startup via `start.sh`. You can also run them manually via Render Shell.

3. **Persistent Storage**: The backend needs a disk mounted at `/data/pdfs` for PDF storage. This is configured in `render.yaml`.

4. **CORS**: Make sure `CORS_ORIGINS` includes your exact frontend URL (including `https://`).
